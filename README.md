# 🔍 Face Age Detection System

Real-time face and age detection using deep learning.

## ✨ Features
- Real-time face detection with OpenCV
- Age estimation using GoogLeNet CNN
- 30+ FPS optimized performance
- Custom cyberpunk HUD UI
- Offline (no cloud needed)

## 🛠️ Tech Stack
- Python 3
- OpenCV
- GoogLeNet CNN (ONNX)
- NumPy, Tkinter

## 🚀 Quick Start

```bash
pip install -r requirements.txt
python main.py
```

## 📁 Folder Structure
- `src/` - Age detector and UI code
- `models/` - Pre-trained models
- `data/` - Sample images

## 🎯 Key Innovations
✓ Frame-skipping for 30+ FPS  
✓ Deque smoothing for stable UI  
✓ Proper tensor preprocessing  
✓ Cyberpunk HUD design  

## Sample Images

To test the system:
1. Add your own image files to the `test/` folder
2. Run `python select_and_test.py`
3. Select an image from `test/` folder
